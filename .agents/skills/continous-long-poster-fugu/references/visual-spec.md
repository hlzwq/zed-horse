# 特雷勒式纸板剪影视觉规范 (Visual Specification · 强化版)

本风格致敬美国民间艺术家比尔·特雷勒（Bill Traylor）与复古民间图文手作美学，融合「粗糙瓦楞纸板底色、毛边折痕肌理、铅笔排线素描轮廓、夸张剪影肢体、低饱和原色平涂与布告栏式网格拼贴」，传递温和、松弛、幽默而富有哲理的市井叙事感。

---

## 1. 纸板材质细节规范 (Cardboard Material Spec)

- **底材**：回收牛皮瓦楞纸板（Weathered corrugated cardboard / Found recycled chipboard）。
- **边缘细节**：画面两侧带有自然的瓦楞撕口毛边（Rough torn corrugated borders / distressed raw paper edges）。
- **表面肌理**：密布深浅不一的木浆纤维微粒、深色木屑杂质斑点（Visible pulp fibers, dark wood specks）、微小折痕与做旧磨损（Soft creases, subtle surface abrasions）。
- **色调基准**：温暖的牛皮纸褐黄色（Kraft Tan `#B89368` ~ `#C8A97A`）。

## 2. 铅笔与色彩体系 (Pencil & 5-Color Palette)

| 角色 | 颜色名称 | 规范与质感 |
| :--- | :--- | :--- |

| **轮廓/排线** | 石墨炭黑 (Graphite Charcoal) | `#1F1E1C`，明显的素描排线与手绘抖动感 |
| **主色 A** | 复古深蓝 (Vintage Navy) | `#243B53`，用于标题字块、大衣、窗帘、茶壶 |
| **主色 B** | 赭红/铁锈红 (Ochre Sienna) | `#8B3A2B`，用于强调标题、木屋屋顶、警示色块 |
| **辅色** | 暖土黄/芥末黄 (Mustard Ochre) | `#C58B35` / `#D49B42`，用于卡片底色块、桌面 |
| **反衬白** | 哑光粉笔白 (Chalk White) | `#F4EBD9`，极少量用于咖啡杯花纹、时钟盘面 |
