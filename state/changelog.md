# Zed Horse · AI 自主视觉创作系统 · 演化记录（给人类）

> 每条只答三问：**变了什么 · 为什么变 · 对你意味着什么**。每里程碑一条，倒序追加；细节见 `state/board.md` 与 git log。

## 2026-08-23 · 图片线并入，系统更名「视觉创作」

**变了什么**：收敛方向从「可直接发布的成片」放宽为「作品（成片 · 图像）」，作品区新增第四类平面图像（海报 / zine / editorial / 封面）；系统名同步改为「AI 自主视觉创作系统」。

**为什么变**：图片产线（gc-zine / photo-abstract / editorial-vision-studio）此前有技能、没身份；同 key、同风格规范、图片本就是视频上游素材，真难题（经验不复利）两线同构——分家只会分裂风格真相源、多养一套账。

**对你意味着什么**：平面作品从此进 `content/`、走同一套验证闭环（规格 · 同族版式 · 返工轮数）；不用再养第二个系统。

## 2026-08-23 · 系统诞生

**变了什么**：Zed Horse · AI 自主视觉创作系统 开仓，作品区 `content/`，收敛方向已写下第一版。

**为什么变**：半年反复踩坑只活在单次会话记忆里，第二次做同类片还要重踩——经验不复利（详见 `.42cog/intent.md` 真难题）。

**对你意味着什么**：手稿写 `content/<作品>/hi.md`（AI 只读）；成品与工程都在 `content/`；每次开工先看 `state/board.md`。
