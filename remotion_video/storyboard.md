# Storyboard — AI 评委，凭什么让人服？

**总时长**: ~110s @ 30fps = ~3300 frames
**场景数**: 8 scenes
**转场**: fade (0.5s = 15f each)

---

## Scene 1: Hook — 心里咯噔一下
- **时长**: 150f (5s)
- **旁白**: 如果你参加比赛，评委是AI——你会不会心里咯噔一下？
- **视觉层级**:
  - **BG**: 深空渐变 (#1a1a2e → #16213e)，微粒子漂浮
  - **MG**: 评委桌 + AI机器人插画（圆角几何体，发光眼睛，法槌图标）
  - **FG**: "AI评委？" 大标题弹出，3个问号气泡依次浮现
  - **UI**: 底部字幕
- **动画**: 机器人spring弹入 → 问号气泡staggered浮现 → 标题scale弹出
- **转场**: fade

## Scene 2: 质疑合理
- **时长**: 210f (7s)
- **旁白**: 评分标准谁定的？有没有人偷偷塞了小纸条？这些质疑，全部合理。但AI做评委，可以做到让人服气。前提是——把它关进笼子里。
- **视觉层级**:
  - **BG**: 同上，粒子继续
  - **MG**: 左侧"小纸条"图标飞入（信封+问号），右侧"✓"勾选标记
  - **FG**: 中央"笼子"概念：一个发光的几何鸟笼图形出现，内含锁图标
  - **UI**: 底部字幕
- **动画**: 小纸条slideIn左侧 → 勾选scaleIn → 笼子bouncy弹入并发出光晕
- **转场**: fade

## Scene 3: 评什么 — 引出维度
- **时长**: 150f (5s)
- **旁白**: 先说评什么。不是随便丢给AI说"你挑最好的"。而是先把"什么叫好"拆清楚，每个维度都有明确说法。
- **视觉层级**:
  - **BG**: 同上
  - **MG**: 左侧"你挑最好的？"虚线框 → 右侧"拆清楚！"实线框+分解箭头
  - **FG**: 中央一个方块被拆分为多个小块的动画（隐喻"拆维度"）
  - **UI**: 底部字幕
- **动画**: 方块出现 → 分解箭头 → 方块碎裂为7+4个小块（预览后续维度数量）
- **转场**: fade

## Scene 4: 文创七维度
- **时长**: 600f (20s)
- **旁白**: 文创和旅游推荐部分，七个维度：主题契合度——跟航线有关还是纯炫技？创意独特性——让人"哇"还是"哦"？视觉完成度——草稿级还是出版级？信息准确性——写的价格景点对不对？实用性——看完想不想真去？文案表达——人话还是机器话？传播效果——转发出去有人看吗？
- **视觉层级**:
  - **BG**: 同上
  - **MG**: 左侧7个维度节点（FlowNode模式：图标+标签），每个有专属图标：
    1. 🎯 靶心图标 — 主题契合度
    2. 💡 灯泡图标 — 创意独特性
    3. 🎨 画板图标 — 视觉完成度
    4. ✅ 勾选图标 — 信息准确性
    5. 🧭 指南针图标 — 实用性
    6. 💬 对话气泡图标 — 文案表达
    7. 📢 扩音器图标 — 传播效果
  - **FG**: 右侧雷达图（7轴），每说明一个维度，对应轴线亮起+填充
  - **UI**: 底部字幕
- **动画**: 节点staggered slideIn左侧 → 雷达图逐轴spring展开 → 每个维度与雷达轴同步高亮
- **转场**: fade

## Scene 5: 英语四维度 + 公示
- **时长**: 390f (13s)
- **旁白**: 英语口语展示部分，四个维度：表达流利度——是自然连贯，还是磕磕绊绊找词？用词准确性——用词地道还是中式英语硬翻？语音语调——发音清晰度、重音节奏对不对？内容表达力——能不能把航线亮点说清楚、说吸引人？所有维度，评审前公示，参赛队可以提意见。维度本身就是权力，必须公开。
- **视觉层级**:
  - **BG**: 同上
  - **MG**: 上方4个维度节点：
    1. 🌊 波浪图标 — 表达流利度
    2. 📖 词典图标 — 用词准确性
    3. 🎵 音符图标 — 语音语调
    4. 🎤 麦克风图标 — 内容表达力
  - **FG**: 右侧波形图（音频波形动画，4段不同频率）→ 末尾"公示"印章盖章效果
  - **UI**: 底部字幕
- **动画**: 节点staggered slideIn → 波形图绘制 → 印章bouncy盖下
- **转场**: fade

## Scene 6: 三模型独立打分
- **时长**: 300f (10s)
- **旁白**: 再说怎么评。三个不同模型独立打分，互不通气。
- **视觉层级**:
  - **BG**: 同上
  - **MG**: 三个AI大脑插画（不同颜色：蓝色/绿色/紫色），各自在一个独立的框内
  - **FG**: 每个大脑旁显示分数卡片（如 85 / 88 / 82），框与框之间有"不通气"的墙壁图标
  - **UI**: 底部字幕
- **动画**: 三个大脑staggered弹入 → 墙壁slideIn → 分数卡片flipIn
- **转场**: fade

## Scene 7: 中位数机制
- **时长**: 300f (10s)
- **旁白**: 最后取三个模型的中位数，不是平均数——至少两个模型同意的结果才能站住。
- **视觉层级**:
  - **BG**: 同上
  - **MG**: 三条分数线汇聚 → 中间值高亮放大
  - **FG**: 左侧"平均数"计算（被划掉）→ 右侧"中位数"计算（被圈起+✓标记），强调"至少两个同意"
  - **UI**: 底部字幕
- **动画**: 分数线slideIn → 中间值pulse高亮 → 平均数fade划掉 → 中位数scaleIn突出
- **转场**: fade

## Scene 8: 总结 — 笼子关好了
- **时长**: 240f (8s)
- **旁白**: AI可以做评委。但前提不是相信它天生公正，是先把它关进一套足够硬的制度笼子里。笼子关好了，出来的结果，谁都服。
- **视觉层级**:
  - **BG**: 同上，但更明亮（背景微亮渐变）
  - **MG**: AI机器人回到笼子里，笼子栏杆上标注三行字："维度公开""独立评分""中位数"
  - **FG**: 笼子发出温暖光晕 → 渐变为"谁都服"大字结尾
  - **UI**: 底部字幕 → fadeOut
- **动画**: 笼子gently放大 → 光晕pulse → 标语fade in → 全场fadeOut
- **转场**: fade to black
