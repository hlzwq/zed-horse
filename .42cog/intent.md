# Zed Horse · AI 自主视觉创作系统 · 意向书

> 意向即行动。这一份文件决定这个系统会长成什么样。
> **只有一处必须你亲自过目：收敛方向。其余是草稿，看不顺眼再动。**
> **它现在一定是粗的。跑完 `-research` 会回来改——四步是循环，不是直线。**

## 收敛方向（唯一）

把「一句想法 → 可直接发布的作品（成片 · 图像）」压成一条 AI 自主干得完的管线；人只出现在两头——定选题、做终审。

怎么算数：进这个系统的每件产出（skill / 规范 / 脚本 / 模板）必须落在两把尺子之一上——① 缩短「想法→成片」的墙钟时长，② 提高终审一次通过率（首版即定稿、无需重渲）。两把尺子都量不出来的产出，不配进系统。量法落实到每件作品记录两个数：**人工介入次数**、**首版→定稿的返工轮数**。

## 真难题

1. **经验不复利**。换一类视频、换一条工具链，坑就重新踩一遍：backdrop-filter 渲染杀手、TTS 限流与换音色重排时间线、竖图进横屏、npm 代理坑……修完只活在单次会话记忆里，第二次做同类片还要再踩。——手工绕不过（人记不全所有坑）；一句提示语解决不了（这是沉淀结构问题，不是提示词问题）；半年 memory 里成串的 gotcha 就是反复投入仍未解的证据。**是它。**
2. **AI 素材的风格与节奏失控**（次级）。模型默认快节奏、随机风格，「静谧电影感」每条片都要重新压。已部分缓解（seedance skill 内置慢节奏、Design/ 规范），但跨模型、跨批次仍反复出现——保持观察，别急着立项。

## 不做什么

| 不做 | 为什么不做 |
|---|---|
| 快节奏强刺激短视频（卡点、流量向） | 风格定位是静谧电影感；「运动必须缓慢」已是用户明令 |
| 训练自有模型、自建渲染农场 | 系统的产出是成片，不是基建；用现成服务（ME AI / shiping / HyperFrames / Remotion） |
| 实时内容（直播、实时字幕转播） | 管线做的是「成片」不是「流」，实时性是另一套工程约束 |
| 素材库式囤积 | 原件进 `vault/raw/` 只读即可；系统的价值在管线，不在囤积 |

## 真相源与权重

冲突时信谁，从高到低（现在填不出来没关系，`-research` 那一步来填）：

1. 用户拍过板的成品与风格规范（`Design/HyperFrames_视频规范.md`、`Design/ME_AI_创作清单.md`、会话中用户的当场否决与确认）——**风格与品味冲突时信这个**
2. 官方一手文档（HyperFrames / Remotion / 即梦 Seedance / ME AI 平台）
3. 实测渲染结果（ffprobe 探针、渲染日志、成片本身）——「事实上跑不跑得通」以它为准；文档过期很常见，坑的最终裁决是重渲一次

## 作品区

- 目录：`content/`
- 系统实际产出什么：四类作品各带全套工程——① 电影感短片（meai-creator / seedance 图生视频，1080P / 16:9 / 15s 级）② 口播讲解片（HyperFrames 时间线，beat-map 式）③ 教学动画（Remotion 场景工程）④ 平面图像：海报 / zine / editorial / 封面（meai 文生图 · 图生图；gc-zine / photo-abstract / editorial-vision-studio 产线）。每件作品 = 成片 MP4 或成图 + 全套工程（脚本 · 分镜 · 音轨 · 提示词与参数 · 可复渲工程）。
- **怎么算合格（验证闭环）**：作品「可直接发布」过四道闸——① 规格校验：视频走 ffprobe（分辨率 / 帧率 / 时长 / 音轨），图像走尺寸与分辨率 ② 视频抽音画对齐与字幕时间轴，图像抽版式是否同族一致 ③ 风格铁律（慢节奏无快移、口播禁 PPT 翻页）④ 记录首版→定稿的返工轮数。**终审（发不发布）永远留给人。**
